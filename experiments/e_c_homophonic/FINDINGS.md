# Family C — homophonic solving

**Status: runs in progress; this file is completed by
`python experiments/e_c_homophonic/summarize.py`.**

## The rule this family is run under

An AZdecrypt-style solver *always* returns something that reads like words. The
only threshold that means anything is the distribution of the identical solver's
best-of-restarts score on surrogates. Zodiac-340 cleared its baseline by many
sigma. **Anything under 3 sigma here is noise and is reported as noise, however
good the output looks.** Every configuration below is reported with its
surrogate baseline and with the digits of pi run through the same pipeline,
side by side.

## Method

`solver.py`: symbol -> letter map over the 27-symbol alphabet `a-z` + space,
searched by simulated annealing (geometric temperature schedule, random symbol
order, `exp(delta/T)` acceptance) followed by a deterministic best-improvement
polish, best of N random restarts. Scoring is character 5-gram log-probability,
reported as **log10 P per plaintext character**. Incremental scoring is
numba-jitted: reassigning one symbol only rescores the 5-gram windows touching
that symbol's positions, with overlapping windows merged so each index is counted
once. The delta was verified exact against a full rescore (30/30 random moves,
`|error| < 1e-3`).

## Language models

CipSoft is German and this is 2001 content, so German is a first-class
hypothesis. Three models were built (`build_lm.py`):

| model | alphabet |
|---|---|
| `en` | English |
| `de_ae` | German, umlauts ASCII-folded `ä→ae`, `ö→oe`, `ü→ue`, `ß→ss` |
| `de_a` | German, cruder folding `ä→a`, `ö→o`, `ü→u`, `ß→ss` |

**Corpus provenance, stated plainly:** general web egress is blocked by this
session's proxy policy (403 on CONNECT to `gutenberg.org`, `wikipedia.org`,
`tibia.fandom.com`), so no running-text corpus — Wortschatz Leipzig,
Gutenberg-DE or otherwise — could be fetched. PyPI *is* reachable, and
`wordfreq` bundles the large Exquisite-Corpus frequency lists (300k word types
per language, from Wikipedia, subtitles, news, books and web text). The models
are therefore built from 20M characters synthesised by sampling word types in
proportion to their corpus frequency. **This captures within-word and
word-boundary character statistics faithfully but carries no syntax beyond word
unigrams**, so it is weaker than a running-text model. It does not bias the
comparison: the real corpus and every surrogate are scored with the identical
model.

Smoothing is interpolated absolute discounting (Kneser–Ney form, D=0.75) with a
minimum-evidence threshold: a context seen fewer than 3 times backs off
wholesale. That threshold is not cosmetic. Without it, junk word types in the
frequency list ("aaa", "zzzz") gave otherwise-unseen 5-gram contexts enough
weight to make a **constant string score better than real English**
(`P(a|aaaa) = 0.44`, giving `-0.359` per char against real text's `-0.633`) —
a degenerate attractor that would have made every Family C result worthless.
Each model is now gated on degenerate strings scoring worse than held-out text:

| model | held-out text | `aaaa…` | `   …` | `abab…` | random |
|---|---|---|---|---|---|
| `en` | -0.633 | -4.88 | -6.01 | -2.81 | -5.12 |
| `de_a` | -0.618 | -4.88 | -6.01 | -2.81 | -5.07 |

## Solver calibration

A negative result from an unvalidated solver is worthless. The solver was run on
homophonic ciphers of real English text at the same sizes as the 469 symbol
streams (`calibrate.py`):

| plaintext chars | symbols | recovered score | true-plaintext score | char accuracy |
|---|---|---|---|---|
| 1200 | 60 | -0.6435 | -0.6511 | **0.999** |
| 1950 | 100 | -0.6310 | -0.6356 | **0.999** |
| 1300 | 374 | -1.177 | — | **0.092** |

The first two are the sizes of the live 469 configurations, and the solver
recovers them essentially perfectly. **The third row is a stated limitation:**
at 374 symbols over 1300 tokens (3.5 observations per symbol, 156 hapax) the
problem is not solvable by any method at this length, so `C1_triples` is
reported as **underpowered by construction**, not as a negative result.
